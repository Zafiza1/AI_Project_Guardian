# AI Project Guardian: frontend

React + TypeScript + Vite + Tailwind CSS v4 dashboard for the Guardian API.

```bash
npm install
npm run dev      # http://127.0.0.1:5173, proxies /api to http://127.0.0.1:8000
npm run build    # type check + production build
npm run lint     # oxlint
```

See the root [README](../README.md) for full setup and the safety model.
